## 安装

到 [Releases 页面](https://github.com/melonlee/LazyBox/releases) 下载对应系统的安装包：

| 系统 | 文件 |
| --- | --- |
| macOS（Apple 芯片） | `LazyBox-<版本>-mac-arm64.dmg` |
| macOS（Intel） | `LazyBox-<版本>-mac-x64.dmg` |
| Windows | `LazyBox-<版本>-win-x64-setup.exe` |
| Linux | `.AppImage` 或 `.deb` |

> 目前安装包**没有经过代码签名**。macOS 首次打开如果提示「无法验证开发者」，请在访达里右键应用 →「打开」；如果提示「已损坏」，在终端执行：
>
> ```bash
> xattr -cr /Applications/LazyBox.app
> ```
>
> Windows 可能弹出 SmartScreen 提示，点「更多信息 → 仍要运行」。

## 工作空间：文章就是文件夹里的 .md

首次打开会看到欢迎页：

- **新建工作空间**：起个名字，再选择一个文件夹
- **打开已有文件夹**：直接打开一个已经放着 Markdown 文件的文件夹

左侧是文件树，支持：

- 新建文件 / 文件夹（顶部按钮或右键菜单）
- 重命名、删除（删除前会确认）
- 拖拽文件到其它文件夹
- 顶部搜索框按文件名过滤

所有文章都是普通的 `.md` 文件，修改后自动保存。你可以用 Git、iCloud、坚果云等任何方式同步或备份这个文件夹，LazyBox 不会上传你的文章。

菜单「File → 关闭工作空间」（⇧⌘W）可以回到欢迎页切换其它工作空间。

## 写作

编辑区右上角有两个按钮：**编辑模式**（只看 Markdown）和**分屏模式**（左边写、右边实时预览公众号效果），分屏时中间的分隔条可以拖动。

工具栏提供加粗、斜体、删除线、超链接、行内代码、格式化文档、插入表格等常用操作。不熟悉 Markdown 的话，记住这几个就够写公众号了：

| 写法 | 效果 |
| --- | --- |
| `## 小标题` | 二级标题 |
| `**重点**` | 加粗 |
| `> 引用` | 引用块 |
| `- 列表项` | 无序列表 |
| `![说明](图片地址)` | 图片，说明文字会显示在图片下方 |
| ` ```js ` 代码 ` ``` ` | 带语法高亮的代码块 |

此外还支持表格、任务列表、Mermaid 流程图等（渲染能力来自 [doocs/md](https://github.com/doocs/md)）。

## 排版：主题、字体、主题色

打开设置面板：macOS 菜单「LazyBox → Settings」（⌘,），Windows / Linux 菜单「File → 偏好设置」。

可以调整：

- **主题**：经典 / 优雅 / 简洁
- **字体**、**字号**、**主题色**（也可以自定义颜色）
- **代码块主题**、图注显示方式、Mac 风格代码块等
- **自定义 CSS**：在默认主题基础上微调任何样式

右侧预览就是复制到公众号后的样子，改完立即生效。

## 图片：上传到图床

公众号后台无法读取你电脑上的图片，所以文章里的图片需要是网络地址。

点击工具栏的「上传图片」（云朵图标），在弹窗里选择图床并填写配置，然后把图片拖进去即可，上传成功后图片链接会自动插入到光标处。支持的图床：GitHub、阿里云 OSS、腾讯云 COS、七牛云、MinIO、Cloudflare R2、公众号图床，以及自定义上传代码。各图床的配置方法可参考 [doocs/md 的说明](https://github.com/doocs/md#支持的图床服务)。

## 发布：复制到公众号 / 导出 Markdown

### 复制到公众号

两种方式效果相同：

1. 顶部的「复制」按钮（下拉可切换「公众号格式 / HTML 格式」）
2. 顶部的「发布」按钮 →「复制到公众号」

然后打开 [公众号后台](https://mp.weixin.qq.com/) →「新的创作 → 文章」，在正文区域粘贴（⌘V / Ctrl+V）。标题、作者、摘要和封面需要在公众号后台单独填写。

通过「发布」按钮复制时，LazyBox 会检查文章里有没有本地路径或 base64 的图片——这些图片粘贴到公众号后会丢失，请先上传到图床。

> LazyBox **不会**替你在公众号自动发文或存草稿。通过官方接口直接存入草稿箱在[路线图](./ROADMAP.md)中。

### 导出 Markdown

「发布」→「导出 .md」会生成一份带 Front Matter 的 Markdown 文件，适合发到 Hexo、Hugo、VitePress 等博客：

```markdown
---
title: "公众号排版的 7 个细节"
author: "你的名字"
date: "2026-11-01"
description: "摘要"
tags: ["写作", "公众号"]
---

正文……
```

菜单「File」里还可以导出 `.md` 和 `.html`。

## AI：发布前校对、拟标题和摘要（可选）

AI 不是必需的，不配置也不影响其它功能。它只做两件事：

- **发布前校对**（菜单「文件 → 发布前校对…」、命令面板，或发布对话框顶部的按钮）：公众号文章发布后正文最多只能改 20 个字，所以发之前让 AI 过一遍错别字、语病、标点 / 中英文空格和重复用词。结果显示在右侧面板，每一条可以定位、接受或忽略，也可以「全部接受」；接受的修改可以 ⌘Z 撤销。只改确定的错误，不改写文风；代码块、链接、Front Matter 不会被改动。长文会分段检查。
- **拟标题和摘要**（发布对话框）：3～5 个不同角度的标题（显示字数，公众号上限 64 字）和一段 120 字以内的摘要，点击填入，也可以复制；不满意可以「换一批」。

在「偏好设置 → AI」里配置：

1. 选择服务商：
   - **Claude (Anthropic)**：填写 API Key，选择模型
   - **OpenAI 兼容**：填 Base URL（下方可一键填 DeepSeek / Kimi / 通义千问 / OpenAI），再填 API Key 和模型名；其它兼容 `chat/completions` 的服务或网关也可以手动填写
2. 点「测试连接」，看到「连接成功」即可

请求由你的电脑直接发送到你选择的服务商，费用按服务商的计费规则由你的账号承担。API Key 保存在本机的应用配置文件中。

## 快捷键

macOS 用 ⌘，Windows / Linux 用 Ctrl。

| 快捷键 | 功能 |
| --- | --- |
| ⌘B / ⌘I / ⌘D | 加粗 / 斜体 / 删除线 |
| ⌘⌥K | 插入超链接 |
| ⌘E | 行内代码 |
| ⇧⌥F | 格式化文档 |
| ⌘N | 新建文件 |
| ⌘, | 设置 |
| ⇧⌘W | 关闭工作空间 |

## 常见问题

**粘贴到公众号后图片不见了？**
图片地址是本地路径或 base64。先用「上传图片」传到图床，或用「发布 → 复制到公众号」，它会提示哪些图片有问题。

**粘贴后样式和预览不一样？**
请确认复制模式是「公众号格式」（「复制」按钮右侧的下拉）。公众号编辑器会过滤部分 CSS（例如自定义字体、部分动画），这是平台限制。

**AI 提示「连接失败」？**
检查 API Key 是否正确、账户是否有余额，以及 Base URL 和模型名是否与服务商文档一致。错误信息会显示服务商返回的原因。

**知乎、掘金能一键发布吗？**
暂不支持。目前可以用「复制」后到对应平台粘贴，或导出 Markdown。

**数据存在哪里？**
文章在你选择的工作空间文件夹里；应用设置（主题、AI 配置等）在系统的应用数据目录中。

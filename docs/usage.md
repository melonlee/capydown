## 安装

到 [Releases 页面](https://github.com/melonlee/LazyBox/releases) 下载对应系统的安装包：

| 系统 | 文件 |
| --- | --- |
| macOS（Apple 芯片） | `LazyBox-<版本>-mac-arm64.dmg` |
| macOS（Intel） | `LazyBox-<版本>-mac-x64.dmg` |
| Windows | `LazyBox-<版本>-win-x64-setup.exe` |
| Linux | `LazyBox-<版本>-linux-<架构>.AppImage` 或 `.deb` |

macOS 是主要开发与测试平台；Windows 与 Linux 安装包从 v0.2.0 起随版本自动构建，实机测试较少，遇到问题欢迎提 [Issue](https://github.com/melonlee/LazyBox/issues)。

> 安装包**没有代码签名**。macOS 首次打开如果提示「无法验证开发者」或「已损坏」，把应用拖进「应用程序」后在终端执行：
>
> ```bash
> xattr -cr /Applications/LazyBox.app
> ```
>
> Windows 可能弹出 SmartScreen 提示，点「更多信息 → 仍要运行」。

## 工作区：文章就是文件夹里的 .md

首次打开会看到欢迎页，可以新建一个工作区，或直接打开一个已经放着 Markdown 文件的文件夹。

- 左侧「文件」侧边栏是文件树：新建文件 / 文件夹、重命名、删除（会先确认）、拖拽移动，支持多层嵌套文件夹，当前文件会高亮
- `⌘P` 快速打开：输入文件名的一部分即可跳转
- 修改自动保存（也可以 `⌘S`）；**只打开、不修改的文件不会被写盘**
- `⇧⌘W` 关闭工作区，回到欢迎页

所有文章都是普通的 `.md` 文件。你可以用 Git、iCloud、坚果云等任何方式同步或备份这个文件夹，懒排不会上传你的文章。

## 用懒排打开 .md 文件（打开方式）

安装后，懒排会登记为 Markdown 文件（`.md`、`.markdown`、`.mdown`、`.mkd`、`.mkdn`）的打开方式，但**不会抢走默认应用**：

- **macOS**：在访达里右键 `.md` 文件 →「打开方式」→「LazyBox」。想以后都用懒排打开：选中文件按 `⌘I`，在「打开方式」里选 LazyBox 并点「全部更改…」
- **Windows**：右键 `.md` 文件 →「打开方式」→「选择其他应用」→ LazyBox（勾选「始终使用此应用」即设为默认）
- **Linux**：文件管理器里右键 →「用其他应用打开」→ LazyBox（`.deb` 安装后登记 `text/markdown`）

打开时的规则和 Typora 一样：文件在当前工作区里就直接打开；不在的话，把它所在的文件夹作为工作区打开（之后在欢迎页的「最近」里也能找到）。懒排已经在运行时，文件会交给已有的窗口，不会再开一个应用。打开文件只读取，不会改动文件。

> macOS 安装包未签名，第一次通过「打开方式」启动若被拦截，先按[安装](#安装)里的说明处理一次。

## 写作

编辑区是单栏「实时预览」：输入 `## 小标题` 后立刻显示成标题，`**重点**` 显示为加粗；光标移进去时才露出 `#`、`**`、`[]()` 等标记，方便修改。

| 写法 | 效果 |
| --- | --- |
| `## 小标题` | 二级标题 |
| `**重点**` | 加粗 |
| `> 引用` | 引用块 |
| `- 列表项` / `1. 列表项` | 无序 / 有序列表 |
| `- [ ] 待办` | 任务列表（可点击勾选） |
| `![说明](图片地址)` | 图片，说明文字显示在图片下方 |
| ` ```js ` … ` ``` ` | 带语法高亮的代码块 |
| ` ```mermaid ` … ` ``` ` | Mermaid 流程图 |
| `---` | 分割线 |

**文件原样保存**：懒排直接编辑 Markdown 文本，预览只是「装饰」，所以不会重排你的格式——换行符（LF / CRLF）、缩进、表格对齐、Front Matter 都保持原样。

常用操作都在菜单「段落」「格式」里，也可以用快捷键，见[快捷键](#快捷键)。`⌥⇧F` 可以格式化整篇文档（这一步会改动格式，按需使用）。

`⇧⌘P` 打开命令面板，输入命令名称（如「专注」「校对」「Night」）即可执行任何菜单命令。

## 编辑区操作：浮动工具栏、右键菜单、「+」插入

界面保持 Typora 式的干净（没有常驻工具栏），常用操作在需要的地方出现。它们执行的都是菜单里的同一条命令，`⌘Z` 可以撤销。

**选中文字 → 浮动工具栏**。选中一段文字（松开鼠标或用 `⇧` + 方向键选好后稍等片刻），选区上方会出现一条黑色小工具栏：加粗、斜体、删除线、行内代码、链接 | 标题 1 / 2 / 3 | 引用。选区已经是某种格式时对应按钮会高亮，再点一次即取消。鼠标悬停可看到快捷键。离窗口顶部太近时工具栏出现在选区下方；开始输入、按 `Esc`、点到别处或用输入法打字时自动收起。

<img src="assets/screenshots/15-floating-toolbar.png" alt="选中文字后出现的浮动工具栏" width="100%">

**右键菜单**。在编辑区右键：剪切 / 复制 / 粘贴 / 全选，「段落」（标题 1–6、正文、列表、引用、代码块）、「格式」（加粗、斜体、删除线、行内代码、链接）、「插入」（图片…、表格…、链接、代码块、分割线）和「发布前校对…」。在链接上右键还有「打开链接」「复制链接地址」，在图片上右键可「复制图片地址」。

**空行左侧的「+」**。光标停在空行上时，正文左边会出现一个浅灰色的「+」（代码块、表格、Front Matter 里不出现；专注模式下隐藏）。点击后选择要插入的内容：标题 1–3、无序 / 有序 / 任务列表、引用、代码块、表格、图片、分割线、Mermaid 图。菜单里可以用 `↑` `↓` 选择、`Enter` 插入、`Esc` 关闭；右侧灰字是对应的 Markdown 写法，顺便记住语法。

<img src="assets/screenshots/16-insert-menu.png" alt="空行左侧的「+」插入菜单（Night 主题）" width="100%">

**左下角的设置与视图**。文件 / 大纲侧边栏底部有三个图标：

- **设置**：打开偏好设置（同 `⌘,`）
- **浅色 / 深色**：在当前浅色主题（GitHub 或 Newsprint）与 Night 之间切换。这是明确的手动选择，所以会同时关闭「跟随系统深色模式」；想恢复跟随，在菜单「主题」里重新勾选即可
- **公众号预览**：打开 / 关闭右侧的公众号预览（同 `⌥⌘P`），打开时图标高亮

侧边栏收起时，设置图标会出现在底部状态栏的最左边，始终一键可达。

<img src="assets/screenshots/17-sidebar-actions.png" alt="侧边栏底部的设置、主题、公众号预览图标" width="100%">

## 视图：侧边栏、专注、打字机、源代码

| 功能 | 快捷键 | 说明 |
| --- | --- | --- |
| 侧边栏 | `⇧⌘L` | 显示 / 隐藏左侧栏 |
| 大纲 | `⌃⌘1` | 侧边栏切到大纲，点击标题跳转 |
| 文件 | `⌃⌘3` | 侧边栏切到文件树 |
| 专注模式 | `F8` | 只有当前段落是清晰的，其余淡出 |

## 编辑器主题

菜单「主题」里有三套编辑器主题：

- **GitHub**（默认）：干净的黑白
- **Newsprint**：纸张底色、衬线字体，适合长文
- **Night**：深色

勾选「跟随系统深色模式」后，系统切到深色时自动用 Night。侧边栏左下角的月亮 / 太阳图标（或命令面板里的「切换浅色 / 深色」）可以一键在浅色与 Night 之间切换，并关闭跟随系统。编辑器主题只影响写作界面，不影响复制到公众号的效果。

## 图片

**粘贴或拖入图片**时，懒排默认像 Typora 一样把图片保存到当前文档旁边的 `assets/` 文件夹，并写入相对路径，例如 `![](assets/photo.png)`。整篇文章连同图片就是一个普通文件夹，换台电脑、换个编辑器都能正常显示。

如果配置了**图床**，粘贴 / 拖入的图片会改为上传到图床并插入网络地址。菜单「格式 → 上传图片…」可以选择图床并填写配置，支持 GitHub、阿里云 OSS、腾讯云 COS、七牛云、MinIO、Cloudflare R2、公众号图床以及自定义上传代码，配置方法可参考 [doocs/md 的说明](https://github.com/doocs/md#支持的图床服务)。

> 公众号后台读不到你电脑上的图片。用本地图片写作完全没问题，只是复制到公众号后，需要在后台重新上传这些图片；或者提前配置图床。

## 公众号排版

`⌥⌘P`（或标题栏右侧的「公众号」按钮）打开右侧的**公众号预览**面板，按公众号的实际效果渲染当前文章。编辑区滚动时预览跟随（单向）。

- **排版样式**：面板里的设置按钮，或菜单「主题 → 公众号排版样式…」。可选经典 / 优雅 / 简洁三套文章主题，调整字体、字号、主题色、代码块主题、图注显示方式等
- **自定义 CSS**：菜单「主题 → 公众号自定义 CSS…」，在文章主题的基础上微调任何样式

这里的颜色与样式属于输出的文章，和编辑器本身的黑白界面无关。

## 发布：复制到公众号 / 导出

### 复制到公众号

`⇧⌘C`、公众号预览面板里的复制按钮，菜单「文件 → 复制到公众号」，或「文件 → 发布…」对话框里的「复制到公众号」，效果相同：用当前排版样式渲染、把样式内联后写入剪贴板。

然后打开 [公众号后台](https://mp.weixin.qq.com/) →「新的创作 → 文章」，在正文区域粘贴（`⌘V` / `Ctrl+V`）。标题、作者、摘要和封面需要在后台单独填写。

如果文章里有本地图片、相对路径或 base64 图片，懒排会提醒你：这些图片粘贴后不会显示，需要在公众号后台重新上传（或先配置图床）。

> 懒排**不会**替你自动发文或存草稿。通过公众号官方接口直接存进草稿箱在[路线图](./ROADMAP.md)中。

### 导出

「文件 → 发布…」对话框里的「导出 Markdown」会生成一份带 Front Matter 的 `.md` 文件，适合 Hexo、Hugo、VitePress 等博客：

```markdown
---
title: "公众号排版的 7 个细节"
author: "你的名字"
date: "2026-11-01"
description: "摘要"
tags: ["写作", "公众号"]
---

正文……
```

菜单「文件 → 导出」里还有 PDF、Word、Markdown 和 HTML，`⇧⌘I` 可以导入已有的 Markdown 文件。

## 导出 PDF / Word

菜单「文件 → 导出 → PDF…」或「Word (.docx)…」，也可以在命令面板 `⇧⌘P` 里搜「导出」。保存位置默认是文章所在的文件夹、与文章同名；导出完成后提示里有「在访达中显示」。

<img src="assets/screenshots/12-export-menu.png" alt="命令面板里的导出命令" width="100%">

**PDF**：按当前编辑器主题排版（GitHub 为无衬线、Newsprint 为衬线；Night 是屏幕主题，导出时用浅色），A4 纸、页脚页码。包含灰阶代码高亮、表格、任务列表、本地图片（`assets/…` 相对路径按文章所在文件夹解析）和 Mermaid 图表；标题不会落在页尾，代码块、图片、表格行尽量不跨页断开。

<img src="assets/screenshots/13-export-pdf.png" alt="导出的 PDF" width="100%">

**Word**：标题（标题 1～6 样式，可直接生成目录）、粗体 / 斜体 / 删除线 / 行内代码、链接、有序 / 无序 / 任务列表（支持嵌套）、引用、代码块（等宽字体 + 底纹）、表格（边框 + 表头行）、分割线，以及图片——本地图片和网络图片都会嵌入文档，并按页面宽度缩小。中文正文用宋体、标题用黑体；没有这些字体的电脑上 Word 会自动替换。

<img src="assets/screenshots/14-export-docx.png" alt="导出的 Word 文档" width="60%">

几点说明：

- Front Matter 不会出现在导出的文件里
- Word 里的 Mermaid 图表以源码形式出现（PDF 里是图）；WebP、SVG 图片不能嵌入 Word，会显示为「[图片：…]」占位
- 网络图片下载失败（超时 10 秒）时同样以占位文字代替，不会让整个导出失败

## AI：发布前校对、标题和摘要

AI 是可选的，不配置也不影响其它功能。它只做两件事：

| 功能 | 为什么需要 | 入口 |
| --- | --- | --- |
| 发布前校对 | 公众号文章发布后，正文最多只能改 20 个字 | 菜单「文件 → 发布前校对…」、命令面板、发布对话框顶部 |
| 标题 + 摘要 | 每篇都要想标题（≤ 64 字）和摘要（≤ 120 字） | 发布对话框里的「AI 拟标题和摘要」 |

### 配置

打开 **偏好设置**（`⌘,`）→ **AI**：

1. **服务商**
   - **Claude（Anthropic）**：填 API Key，选择模型（Opus 4.7 / Sonnet 4.6 / Haiku 4.5）
   - **OpenAI 兼容**：DeepSeek、Kimi、通义千问、OpenAI，以及任何兼容 `chat/completions` 的网关。点「快速填写」里的服务名可以一键预填 Base URL 和常用模型
2. **Base URL**（OpenAI 兼容）：通常以 `/v1` 结尾，懒排会在后面拼上 `/chat/completions`

   | 服务 | Base URL | 模型示例 |
   | --- | --- | --- |
   | DeepSeek | `https://api.deepseek.com/v1` | `deepseek-chat` |
   | Kimi | `https://api.moonshot.cn/v1` | `moonshot-v1-8k` |
   | 通义千问 | `https://dashscope.aliyuncs.com/compatible-mode/v1` | `qwen-plus` |
   | OpenAI | `https://api.openai.com/v1` | `gpt-4o-mini` |

3. **API Key**、**模型**
4. 点 **测试连接**，看到成功提示后保存。修改 Key 或模型后无需重启

### 发布前校对

1. 打开要发的文章，执行「发布前校对…」
2. 校对面板会按段落把正文发给你配置的服务，并显示进度；长文会分批并行检查，某一批失败不影响其它批，面板会告诉你哪几行没检查成功
3. 结果按类型列出：**错别字、语病、标点、重复用词**。每一条可以：
   - **定位**：点击条目，编辑器跳到原文并选中
   - **接受**：写入建议的改法，可以 `⌘Z` 撤销
   - **忽略**：从列表里移除
4. **全部接受**：一次写入所有剩余建议，一次 `⌘Z` 就能全部还原

校对**只挑确定的错误，不改写文风**。代码块、行内代码、链接地址、图片、Front Matter、HTML 不会被改动；改动过大、增删换行、改动 Markdown 标记的建议会被直接丢弃。校对后你又改了文章也没关系，懒排会按原文和上下文重新定位；找不到的条目标记为「原文已改动」。

**风格建议（可选）**：中文与英文、数字之间是否加空格属于风格问题，默认不报。需要的话，在校对面板首屏或「偏好设置 → AI」里勾选「校对时包含风格建议」，这类建议会单独列为一组。

### 标题和摘要

在「文件 → 发布…」对话框里点「AI 拟标题和摘要」，会根据全文生成 3～5 个标题候选（每个不超过 64 字）和一段不超过 120 字的摘要。点击候选可以填入，右侧按钮可以复制，然后到公众号后台粘贴。

### 隐私与费用

- 只有你主动点击校对或拟标题时，文章内容才会从你的电脑直接发到你配置的服务商
- 懒排没有自己的服务器，不经手你的文章和 Key；Key 只保存在本机的应用配置里
- 费用由你的服务商按用量计算

## 快捷键

macOS 下的 `⌘` 在 Windows / Linux 上是 `Ctrl`，`⌥` 是 `Alt`。少数 `⌃⌘` 组合在 Windows / Linux 上换成了不冲突的按键（见下表）。菜单里显示的快捷键与实际生效的一致。

### 文件

| 操作 | macOS | Windows / Linux |
| --- | --- | --- |
| 新建文件 | `⌘N` | `Ctrl+N` |
| 快速打开 | `⌘P` | `Ctrl+P` |
| 保存 | `⌘S` | `Ctrl+S` |
| 导入 Markdown | `⇧⌘I` | `Ctrl+Shift+I` |
| 导出 PDF / Word | 菜单「文件 → 导出」或命令面板 | 同左 |
| 关闭工作区 | `⇧⌘W` | `Ctrl+Shift+W` |
| 偏好设置 | `⌘,` | `Ctrl+,` |
| 命令面板 | `⇧⌘P` | `Ctrl+Shift+P` |

### 编辑

| 操作 | macOS | Windows / Linux |
| --- | --- | --- |
| 撤销 / 重做 | `⌘Z` / `⇧⌘Z` | `Ctrl+Z` / `Ctrl+Shift+Z` |
| 查找 | `⌘F` | `Ctrl+F` |
| 格式化文档 | `⌥⇧F` | `Alt+Shift+F` |

### 段落

## 已知差距

懒排以 Typora 为参照，但还有这些不足：

- 表格在光标进入后以 Markdown 源码编辑，没有表格控件（`⌥⌘T` 可插入表格模板）
- 数学公式和 HTML 块按源码显示，不做渲染
- 从网页粘贴富文本时按纯文本插入，不会转成 Markdown
- 公众号预览只跟随编辑区滚动（单向同步）
- 发布只能通过剪贴板，还不能直接存进公众号草稿箱

## 常见问题

**复制到公众号后图片不显示？**
公众号后台读不到本地图片。在后台重新上传，或配置图床后再粘贴图片，见[图片](#图片)。

**粘贴到公众号后样式和预览不一样？**
请在公众号后台「新的创作 → 文章」的正文区域直接粘贴，不要先粘到其它编辑器再转贴。公众号会过滤掉一部分 CSS，这类样式以公众号后台的实际显示为准。

**AI 提示「未配置」或「连接失败」？**
到「偏好设置 → AI」点「测试连接」。OpenAI 兼容服务请确认 Base URL 以 `/v1` 结尾、模型名与服务商一致、账户有余额。

**校对漏掉了某个错字？**
AI 校对不能保证百分之百，它是发布前的最后一道帮手，不是唯一一道。

**文章存在哪里？**
就在你打开的工作区文件夹里，懒排不会另存副本。

**想用 Typora / Obsidian 打开同一个文件夹？**
可以。懒排写的是标准 Markdown，图片是相对路径，互不影响。

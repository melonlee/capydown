# 路线图

懒排只解决一个问题：**让公众号作者安静地写，一键排好，发出去之前没有错字。**
新功能先问一句：它能不能让「写 → 排 → 校 → 发」这条链路更短、更稳？不能就不做，或者放进「实验功能」。

- [x] 源代码模式、文件 / 大纲侧边栏、专注与打字机模式、快速打开、命令面板

- [x] 黑白界面、新品牌、启动动画

## 下一步（v0.3）

按对公众号作者的价值排序：

1. **表格可视化编辑**：光标进入表格时用表格控件编辑（增删行列、对齐、Tab 跳格），保存时仍是原样的 Markdown
2. **公众号草稿箱直传**：填写 AppID / AppSecret 后，通过公众号官方接口把文章（含封面、摘要、上传后的正文图片）存进草稿箱。需要作者自己的公众号开通接口权限并配置 IP 白名单；Secret 只存本机
3. **数学公式渲染**：行内与块级公式在编辑区渲染，复制到公众号时转为图片
4. **从网页粘贴转 Markdown**：粘贴富文本时保留标题、列表、链接、图片
5. **公众号预览双向滚动同步**
6. **macOS 签名与公证、自动更新**（需要 Apple Developer 账号）
7. **Windows / Linux 实机测试**：安装、菜单与快捷键（`Ctrl` 组合键冲突）、字体、剪贴板、高分屏

## 实验功能（默认关闭）

以下模块有原型代码，但还不够可靠，默认不注册：

- MCP 插件 / Skill 系统
- 向量检索、知识图谱、知识问答
- 排版模板系统
- AI 生图、去背景、风格迁移
- 通用 AI 写作助手（续写、润色、扩写、大纲）
- 知乎、掘金、语雀、飞书、Notion 一键发布

源码在 `src/main/` 下保留，在 `electron-store` 中把 `experimental_features_enabled` 设为 `true` 并重启即可注册。欢迎 PR 把其中任何一项做到可用。

## 不做什么

- 不做通用笔记 / 知识库软件
- 不做云同步与账号体系：文章就是你硬盘上的 `.md` 文件
- 不在没有真实接口的平台上假装「一键发布」
- 不让 AI 替你写文章

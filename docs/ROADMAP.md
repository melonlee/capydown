# 路线图

LazyBox 只解决一个问题：**让公众号作者从写作、排版、配图到发布，少做重复劳动。**
新功能先问一句：它能不能让这条链路更短？不能就不做，或者放进「实验功能」。

## v0.2.0（进行中）

- [x] 发布对话框：复制到公众号 / 导出带 Front Matter 的 Markdown，结果如实反馈
- [x] 本地图片检测：复制前提醒先上传图床
- [x] AI 起标题、写摘要、润色、续写；支持 Claude 与 OpenAI 兼容接口（DeepSeek、Kimi、通义千问等）
- [x] 安全加固（沙箱、链接白名单、IPC 收紧）
- [x] 新品牌、CI 与多平台 Release 工作流
- [ ] 发布 Windows / Linux 安装包

## 下一步（v0.3）

按对公众号作者的价值排序：

1. **公众号草稿箱直传**：填写 AppID / AppSecret 后，通过公众号官方接口把文章（含封面、摘要）直接存进草稿箱。需要作者自己的公众号开通接口权限并配置 IP 白名单
2. **图片一条龙**：粘贴 / 拖入图片时自动压缩、自动上传，并把正文里的本地图片批量替换为图床地址
3. **手机预览**：按公众号实际宽度预览，标出过长段落、过大图片
4. **主题库**：更多为中文长文调校过的主题，支持导入 / 导出自定义 CSS
5. **macOS 签名与公证、自动更新**（需要 Apple Developer 账号）

## 实验功能（默认关闭）

以下模块有原型代码，但还没有可靠到值得默认开启：

- MCP 插件 / Skill 系统
- 向量检索、知识图谱、知识问答
- 排版模板系统
- AI 生图、去背景、风格迁移
- 知乎、掘金、语雀、飞书、Notion 一键发布

它们的源码在 `src/main/` 下保留，在 `electron-store` 中把 `experimental_features_enabled` 设为 `true` 并重启即可注册相应接口。欢迎 PR 把其中任何一项做到可用。

## 不做什么

- 不做通用笔记 / 知识库软件
- 不做云同步与账号体系：文章就是你硬盘上的 `.md` 文件
- 不在没有真实接口的平台上假装「一键发布」

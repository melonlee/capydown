Writing

Writing is just writing.

Type Markdown and see it typeset instantly. Markers appear only where your cursor is; the rest of the time there is only your text.

Three editor themes, following the system dark mode if you like

Live preview

Built on CodeMirror 6: headings, emphasis, images, tables and Mermaid render as you type.

Byte-exact files

Open, don’t edit, close — the file is unchanged. Line endings, indentation and table alignment are never reformatted.

Focus & typewriter

F8 dims everything but the current paragraph; F9 keeps the current line centred.

Outline & files

⇧⌘L toggles the sidebar; switch between the file tree and an outline you can click to jump.

Quick open & palette

⌘P finds articles, ⇧⌘P finds commands, ⌘/ flips to source mode.

Images stay close

Pasted or dropped images go to assets/ beside the document with a relative path — or to your image host.

In the editor · v0.3.0

Everything within reach.

No permanent toolbar. Select text and a floating toolbar appears; rest on an empty line and a “+” shows up; right-click for a native menu. All of them run the same commands as the menus, and all can be undone.

Floating toolbar

Bold, italic, strikethrough, inline code, link, headings 1–3, quote. Active formats are highlighted; hover for the shortcut.

“+” on empty lines

Insert a heading, list, quote, code block, table, image, divider or Mermaid diagram — arrow keys and Enter work.

Right-click & sidebar

Paragraph, format, insert and proofread on right-click; settings, light / dark and the 公众号 preview at the sidebar’s bottom-left.

Two AI helpers

One more look before it ships.

Once published, WeChat lets you change at most 20 characters of an article. So AI in Slothdown does exactly two things, both before you hit publish.

Pre-publish proofreading

Only definite errors, never a rewrite of your voice. Every change is your call.

  • Typos, grammar, punctuation, repeated words
  • Jump, accept or ignore; accept all, undo with one ⌘Z
  • Code, links and front matter are never touched
  • CJK/Latin spacing is an opt-in style suggestion

Titles + summary

Candidates drafted from the full text, right in the publish dialog.

  • 3–5 titles, ≤ 64 characters each
  • A summary of ≤ 120 characters
  • Click to fill in, or copy for the WeChat backend
  • Everything else works without AI

Your key.
Your text never touches us.

Bring your own API key. Requests go straight from your computer to the provider you choose. Slothdown has no server; your key stays on your machine.

Text is sent only when you start a proofread or ask for titles.

FAQ

Questions

Why “Slothdown”? What happened to LazyBox?

Slothdown is Markdown with a sloth — and “slow down”: calm, focused writing. Its Chinese slogan 懒得排版？交给树懒。 means “too lazy to format? leave it to the sloth”. Since v0.3.1 Slothdown is the only name. It is the same app as LazyBox · 懒排, renamed in v0.3.0. Existing users just install the new version: preferences, AI settings and the workspace list are carried over on first launch, and the old data is left untouched.

Is Slothdown related to Typora?

No. Slothdown is an independent open-source project that takes Typora as its reference for the writing experience. What it adds is 公众号 formatting and pre-publish proofreading; if you don’t write for WeChat, Typora remains a great choice.

Is it free? Do I need an account?

Free and open source (MIT), no account. AI uses your own API key and is billed by your provider; writing and formatting work fully without it.

Which platforms are supported?

macOS (Apple silicon and Intel) is the primary development and test platform. Windows and Linux builds (Slothdown-<version>-…) are produced automatically with each release and are lightly tested — bug reports welcome.

macOS says the app is “damaged”?

The build isn’t signed yet. Move it to Applications and run xattr -cr /Applications/Slothdown.app in Terminal.

Images disappear after pasting into WeChat?

WeChat can’t read files on your computer. Slothdown warns you before copying; re-upload those images in the backend, or configure an image host (GitHub, Aliyun OSS, Tencent COS, Qiniu, Cloudflare R2 …) so new images upload on paste.

What’s missing compared with Typora?

Tables are edited as Markdown source, math and HTML blocks aren’t rendered, rich text from the web pastes as plain text, and the 公众号 preview scroll sync is one-way. All on the roadmap.
